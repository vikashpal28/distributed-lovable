# Project Companion

Project Companion is an AI-powered coding workspace designed to help developers build and manage projects faster. It features an integrated chat panel for AI assistance and a code panel for seamless editing and viewing.

## Features

- **Projects Dashboard:** Manage and view all your active workspaces.
- **AI Chat Panel:** Get contextual help, code generation, and debugging assistance.
- **Code Editor:** View and edit your code directly in the browser.
- **User Authentication:** Secure signup and login for personalized workspaces.
- **Deployment Previews:** Showcase and share live previews of your deployed projects.
- **Export & Delete:** Easily download your project as a ZIP file or safely delete it when no longer needed.

## Tech Stack

- **Frontend Framework:** [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **UI Components:** [shadcn/ui](https://ui.shadcn.com/)
- **Routing:** React Router v6
- **Code Editor:** CodeMirror
- **Icons:** Lucide React

## Getting Started

### Prerequisites

Ensure you have Node.js and npm installed.

### Installation

1. Clone the repository:
   ```bash
   git clone <YOUR_GIT_URL>
   ```

2. Navigate to the project directory:
   ```bash
   cd frontend 
   cd project-companion
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

### Running Locally

Start the development server:

```bash
npm run dev
```

The app will be available at `http://localhost:5173`.

### Building for Production

To create a production build:

```bash
npm run build
```
